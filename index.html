Disconnected
This browser can't open USB devices (Safari, Firefox, and every browser on iPhone and iPad). You can still use the engraver:
  • open this page in Chrome or Edge (on Android: Chrome), or
  • run the bridge on the computer the engraver is plugged into, python3 bridge.py, and open http://localhost:8766. For a phone or tablet, run python3 bridge.py --lan and open the address it prints.
The Demo works in every browser. Instructions: see the README on GitHub.

Ways to connect

Chrome / Edge on Windows, macOS, Linux and ChromeOS

Bridge: for Safari, Firefox, iPhone and iPad. Run python3 bridge.py next to this page's file (see README); the page it serves connects automatically.
